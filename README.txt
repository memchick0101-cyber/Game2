Хроники Эйрвальда 3.5.0

ВАЖНО ДЛЯ GITHUB PAGES:
1. Распакуйте архив.
2. Откройте папку с файлами index.html и README.txt.
3. Загрузите СОДЕРЖИМОЕ этой папки прямо в корень репозитория GitHub Pages.
4. Не загружайте ZIP-архив как файл и не оставляйте index.html внутри вложенной папки chronicles_of_eyrval.
5. В корне репозитория должен лежать именно index.html.
6. В GitHub проверьте Settings -> Pages: публикация должна идти из нужной ветки и папки / (root).
7. После публикации откройте сайт в Safari и обновите страницу. Если показывается старая версия, очистите данные сайта/кэш Safari или откройте приватную вкладку.

Сохранения предыдущих версий остаются в localStorage браузера.
