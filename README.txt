ХРОНИКИ ЭЙРВАЛЬДА 5.2.0 — ОТГОЛОСКИ ПОКОЛЕНИЙ

Установка:
1. Распакуйте архив.
2. Загрузите index.html в корень репозитория GitHub Pages, заменив предыдущий файл.
3. Откройте опубликованную страницу. Сохранение использует прежний ключ localStorage: eyrval_save.

Главное обновление 5.2.0:
- Добавлены сюжетные нити «Долг старого каравана», «Пепел старой рощи» и «Голос под руинами».
- У каждой истории есть несколько решений с разными последствиями, а незавершённая нить переносится к выбранному наследнику.
- Итоги решений записываются в семейную летопись и сохраняются между поколениями.
- Потомки могут встречать людей и фракции, которые помнят решения предков: караванный союз, страх перед грабителями, благодарность хранителей рощи или последствия пробуждённой печати.
- Архив рода показывает незавершённые истории и уже оставленные семейные последствия.
- Новые поля инициализируются автоматически для старых сохранений; ключ сохранения и прежние данные не менялись.

Проверки:
- JavaScript: node --check — успешно.
- HTML: повторяющихся ID не обнаружено.
- ZIP: целостность проверена.
- Полноценный интерактивный прогон в iPhone Safari не выполнялся.
