# Хроники Эйрвальда 3.3.4

## Исправления
- Исправлена критическая ошибка запуска JavaScript: список действий обращался к `s.race` до создания игрового состояния. Из-за этого скрипт останавливался до назначения обработчиков, поэтому все кнопки выглядели декоративными.
- Описание родового дара теперь подставляется во время отрисовки интерфейса и соответствует выбранной расе.
- Сохранение обёрнуто в обработку ошибок: если браузер блокирует localStorage, игра не ломается и показывает уведомление.
- Сохранены звуковые эффекты и переключатель звука из версии 3.3.3.

## Проверки
- Проверен синтаксис JavaScript (`node --check`).
- Проверен запуск в Chromium: стартовый экран, создание персонажа, назначение обработчиков основных кнопок, переход года, выполнение действия, открытие казны, переключение звука и обработка случайного события.
- Проверка на реальном iPhone/Safari не выполнялась.

## Запуск
Откройте `index.html` в браузере или опубликуйте папку `chronicles_of_eyrval` через GitHub Pages. Сохранение хранится в localStorage браузера.
