# Хроники Эйрвальда

Мобильная браузерная RPG о жизни героя в фэнтезийном средневековье. Игра сделана на чистом HTML/CSS/JavaScript — без сборки и серверной части.

## Публикация через GitHub Pages

1. Создай новый публичный репозиторий на GitHub, например `eyrval-chronicles`.
2. Загрузи в корень репозитория файл `index.html`.
3. Открой **Settings → Pages**.
4. В разделе **Build and deployment** выбери **Deploy from a branch**.
5. Выбери ветку `main` и папку `/ (root)`, затем нажми **Save**.
6. Через минуту GitHub покажет адрес вида `https://ТВОЙ-АККАУНТ.github.io/eyrval-chronicles/`.

## Как играть на iPhone

Открой опубликованный адрес в Safari → кнопка «Поделиться» → **На экран Домой** → «Добавить». Игра будет запускаться с иконки как отдельное веб-приложение. Прогресс сохраняется в локальном хранилище браузера на этом устройстве. Кнопка «Сохранить» делает ручное сохранение.

## Игровой цикл

- У героя случайные начальные характеристики; удача не тренируется.
- Каждый год даёт 3 действия: магия, меч, отдых, исследование, охота, общение, работа, любовь и подвиги.
- После выполнения действий нажми «Прожить год».
- С возрастом меняются жизненные этапы и растёт риск смерти.
- Можно создать семью, оставить потомков и после смерти продолжить игру за ребёнка.
- Сохранение хранится на устройстве и в том же браузере.

## Сброс сохранения

Чтобы начать с чистого листа, открой инструменты разработчика браузера и удали ключ `eyrval_save` из `localStorage`, либо очисти данные сайта.
